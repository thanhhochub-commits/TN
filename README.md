# TN - Ôn tập Chủ nghĩa xã hội khoa học

Website trắc nghiệm **350 câu / 7 chương**.

## Chức năng chính
- Ôn từng chương hoặc trộn nhiều chương.
- Xáo câu hỏi và xáo vị trí đáp án A, B, C, D.
- Chọn đúng: đáp án đúng hiện màu xanh và giải thích ngay bên dưới.
- Chọn sai: lựa chọn sai hiện màu đỏ, đáp án đúng hiện màu xanh, kèm giải thích.
- Tự lưu câu sai, câu yếu, câu đánh dấu và lịch sử làm bài.
- Chế độ ôn tập và kiểm tra.
- Thống kê tiến độ theo từng chương.
- Lưu dữ liệu ngay trên trình duyệt, không cần máy chủ hoặc khóa API.
- Hỗ trợ giao diện sáng/tối và điện thoại.

## Tệp chính
- `index.html`: website hoàn chỉnh, đã nhúng đủ 350 câu.
- `questions.json`: dữ liệu nguồn đầy đủ 350 câu.
- `.nojekyll`: giữ nguyên website tĩnh khi chạy GitHub Pages.

## Bật GitHub Pages
Vào **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → /(root) → Save**.

Sau khi GitHub Pages xuất bản, địa chỉ dự kiến là:
`https://thanhhochub-commits.github.io/TN/`
